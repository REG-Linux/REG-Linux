# Amiberry

Amiga emulator. Upstream: https://github.com/BlitterStudio/amiberry

Uses SDL3. Installs the `whdboot/` and `data/` trees to `/usr/share/amiberry/`, AROS open-source BIOS ROMs to `/usr/share/reglinux/datainit/bios/amiga/`, and default config directories under `/usr/share/reglinux/datainit/system/configs/amiberry/`.
