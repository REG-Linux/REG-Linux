# duckstation-mini

PlayStation 1 emulator, ImGui frontend (AppImage). Upstream: https://github.com/stenzek/duckstation

ARM/AArch64-only pre-built AppImage (`DuckStation-Mini-armhf.AppImage` / `DuckStation-Mini-arm64.AppImage`). Installed to the same path as duckstation: `/usr/duckstation/DuckStation.AppImage`.
