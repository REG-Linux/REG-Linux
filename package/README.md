# REG-Linux packages

Upstream: https://github.com/REG-Linux/REG-Linux

The `package/` tree houses every Buildroot recipe REG-Linux maintains. Each folder is self-contained: a `Config.in`, the `.mk` recipe, and any patches, keys, or assets needed at build time. The subtrees are `emulators/`, `engines/`, `ports/`, `games/`, `system/`, and `batocera/` (controller, boot, and core helpers inherited from the Batocera lineage).
