# reglinux-scummvm

Pre-built ScummVM bundle for REG-Linux. Upstream: https://github.com/REG-Linux/REG-ScummVM

Downloads a pre-built architecture-specific tarball (bcm2835, bcm2836, odroidxu4, rk3288, jz4770, s812, etc.) rather than compiling from source. Provides `BR2_PACKAGE_HAS_SCUMMVM` and `BR2_PACKAGE_HAS_LIBRETRO_SCUMMVM` virtual packages.
