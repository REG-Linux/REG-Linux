# OpenBOR

Multiple OpenBOR engine revisions packaged independently so users can pick the version that best runs their `.pak` files. Upstream: https://github.com/DCurrent/openbor

Each subdirectory (`openbor4432` through `openbor7530`) compiles a distinct fork commit and installs its binary under a versioned name (e.g. `OpenBOR6330`) so all variants can coexist on the target.
