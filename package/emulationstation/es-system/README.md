# es-system

`es-system.py` generates `es_features.cfg` and `es_systems.cfg` from the YAML sources at build time. `es_systems.yml` defines system metadata and controls what text appears in the per-system `_info.txt` files inside `roms/`. `es_features.yml` declares per-emulator option menus consumed by EmulationStation alongside the configgen generators. The `roms/` subdirectory bundles freely-licensed homebrew titles that ship pre-installed.
